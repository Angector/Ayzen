# Target Models — مدل‌های هدف

## مدل‌های تصویر

| مدل | گویش | چه می‌خواهد |
|---|---|---|
| **Flux** | سینمایی/عکاسی | دوربین، فیلم، DOF |
| **Midjourney V7** | زیبایی‌شناسانه | Ethereal، palette |
| **Ideogram V3** | متن‌محور | متن داخل گیومه |
| **Imagen 4** | نثر رمانی | توصیف صحنه |

## مدل‌های ویدیو

| مدل | فرمول کلیدی | دام رایج |
|---|---|---|
| **Kling** | Subject → Action → Scene → Style | چند حرکت دوربین |
| **Veo** | نثر سینمایی + بلوک صدا | نادیده گرفتن صدا |
| **Seedance** | روایت بلند + تگ مرجع | پرامپت کوتاه |

## مدل‌های توسعه

| مدل | مناسب برای |
|---|---|
| **Cursor** | ویرایش چندفایلی، ریفکتور |
| **Claude Code** | بازبینی، معماری، shell |
| **v0** | UI-first |
| **Lovable / Bolt** | پروتوتایپ سریع |

## قانون

هر پرامپت در داده‌ها فیلد `model` دارد و مقدار آن باید از این فهرست باشد.
